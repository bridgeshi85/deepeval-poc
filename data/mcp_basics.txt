Model Context Protocol (MCP) is an open protocol for connecting language-model applications to external tools and data sources in a consistent way.

MCP usually involves three roles. A host application runs the user experience, a client manages the connection to MCP servers, and a server exposes capabilities such as tools, resources, or prompts.

An MCP server can provide structured tools that the model may call, resources that the model can read, and prompts that help standardize common tasks.

Teams use MCP to avoid building one-off integrations for every tool. It gives a standard interface for connecting assistants to internal systems, knowledge bases, APIs, and productivity tools.

In a retrieval-augmented generation application, MCP can help the assistant discover and use external context safely and consistently instead of relying only on the model's built-in knowledge.

This demo knowledge base is intentionally small so it is easy to evaluate with DeepEval and RAGAS. The goal is not perfect coverage but a stable local target for evaluation experiments.
